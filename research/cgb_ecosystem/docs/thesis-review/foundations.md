## What this subset changes in the assessment

The current CAD experiment is a sound place to start testing these ideas: it distinguishes hidden causes from observations, preserves receiver-time availability, freezes fitting across stress worlds, prices a linked bond ecosystem, and produces one coherent distribution over empirical paths **within each horizon**. The corpus suggests a richer next question than whether a physical analogy is literally true: **which distinctions, memories, reference changes, and feedback operations must the model preserve to remain useful under a change of mechanism?**

The strongest gaps are specific and testable without market data:

1. **Memory matching, not merely more indicators.** Hold observed one-step marginals roughly fixed while changing temporal organization and test which history representation captures the conditional predictive information.
2. **Structural contribution versus endpoint classification.** At 60 minutes the three base fits give essentially all mixture weight to the supervised endpoint expert. Because that expert redistributes probability by endpoint class, summing its path weights by class recovers the classifier probabilities when all classes have support. State mechanics can be present in the architecture without contributing to the successful one-hour direction result. The local paths still determine within-class magnitude and excursion behavior. Evaluate those contributions separately.
3. **Scale and reference compatibility.** Separate horizon banks need not be marginals of a common process; coordinate changes through yield, duration, price, and CTD selection need not commute. Measure those discrepancies instead of assuming that normalizing a feature makes it invariant.
4. **Updating state versus adapting rules.** The current system updates observations and forecasts; `matured_feedback` only scores. This is a useful frozen baseline, but it does not test the proposed cybernetic governor's response to persistent model failure.
5. **Observational equivalence and endogenous action.** Different hidden mechanisms can produce the same available observations; conversely, introducing own-order impact can change the future distribution. An honest model needs tests for both limits.
6. **Finite-episode viability and path risk.** Low entropy, endpoint log-loss improvement, good path-risk coverage, and acceptable execution are distinct accomplishments. Optimizing class log loss cannot reward a better allocation of probability among paths inside the same class.

These are proposed discriminating experiments, not claims that their outcomes are already known.

## 1. Leveraging Environmental Correlations: The Thermodynamics of Requisite Variety

Alexander B. Boyd, Dibyendu Mandal, and James P. Crutchfield. Collected paper, 19 pages. [Original text](coverage.md#c01).

**Passages.** Memory synopsis beginning line 184; the memory/correlation discussion around lines 499–795; §IV, “Achievability of Bounds,” lines 1050–1580; Appendix A beginning line 1694, including its alphabet/detailed-balance qualifications.

**Mechanism.** Temporal correlation is an information resource different from the marginal bias of the next symbol. A memoryless transducer cannot generally exploit correlations in a memoryful input. The relevant structure includes entropy rate and the information past observations carry about future observations; a favorable bound is not proof that a particular finite mechanism attains it. The strongest optimality statement for memoryless input has a binary-input qualification. Infinite-state examples change the resource accounting and stationarity assumptions.

**Reconstructed question.** Which information about the next hour is in the history but absent from our current state, and how much controller memory is needed to preserve it without retaining useless past detail?

**Right / wrong / missing.** The model already includes multi-window movement, state age, flow and response. That is more consistent with this paper than a memoryless sign classifier. Its reported predictive entropy is nevertheless only the entropy of three endpoint classes; interpreting it as entropy rate, information gain, or environmental complexity would be wrong. Missing: tests that distinguish excess temporal information from easy marginal differences, and tests of whether the observed state is a sufficient predictive compression. The fast-decay failure may reflect mismatched memory and horizon, not a general impossibility of prediction.

**No-data experiment.** Construct binary or finite-state pressure processes with identical stationary one-step marginals, similar volatility, and different hidden memory order or dwell times; reprice the same bond ecosystem. Compare no-history, current features, finite-history, and known-generator filtering oracles. Estimate held-out log-score gains conditional on history and the extra gain from adding memory after the existing state. Vary predictor memory and generator memory independently. A benefit that disappears after matching marginals is not evidence of exploiting temporal structure. These are information-theoretic experiments; no conversion of forecast skill into thermodynamic work is required.

**Limit.** Available diagram/equation extraction is damaged. In particular, do not import an appendix sign or generalize its binary proof without checking the original mathematical rendering.

## 2. Redundant Attempted Solutions: Operative Diagnoses and Strategic Interventions to Disrupt More of the Same

Grégoire Vitry, Claude de Scorraille, Claudette Portelli, and Michael F. Hoyt. Collected clinical/systemic paper, 18 pages. [Original text](coverage.md#c02).

**Passages.** “The Attempted Solution as the Problem,” lines 99–161; feedback/control–avoidance treatment around 187–278; operative questions at 281–301; intervention strategies and vignette around 362–578; limitations around 580–619.

**Mechanism.** A problem can persist because the attempted corrective response recreates the conditions sustaining it. The useful diagnosis is functional: who responds, to what, when, and with what next consequence? An intervention changes that maintaining loop. “180 degrees” is not a theorem recommending that every failed action be blindly inverted.

**Reconstructed question.** When our model fails, is the next repair learning about the environment, or is the repair itself making the evidence noisier and forcing another repair?

**Right / wrong / missing.** The frozen experiment and preserved failures avoid a common self-reinforcing research loop. Existing recovery-failure features describe price behavior; they do not diagnose a controller repeatedly changing its rules. It would be wrong to label every drawdown a double bind or make “reverse the trade” the generic response. Missing: explicit experimental models of adaptation failure.

**No-data experiment.** Add an outer loop in a separate branch that shortens memory or increases update gain after recent mature losses. Compare it with frozen fitting and a rule with delayed evidence, deadband, and minimum dwell between changes. Independently vary disturbance duration and label delay. Measure parameter oscillation, false interventions, recovery time, and held-out proper loss, retaining every attempted policy. Switch off only the suspected maintaining loop. This distinguishes an effective corrective response from a response that amplifies temporary noise.

**Limit.** Clinical results and illustrative cases are not causal validation of a trading intervention. The transferable object is the feedback topology and an intervention design.

## 3. A Formal Definition of Scale-dependent Complexity and the Multi-scale Law of Requisite Variety

Alexander F. Siegenfeld and Yaneer Bar-Yam. Collected mathematical paper, 18 pages, June 2025 version. [Original text](coverage.md#c03).

**Passages.** Definitions 1–3 at 159–211; complexity profiles and nested partitions at 255–400; multi-scale law/sum rule at 402–462; choice of partition at 463–599; combining independent systems and copies at 600–729.

**Mechanism.** Requisite variety concerns distinctions that require distinct responses. The profile depends on a specified partition scheme and how components coordinate at different scales. Duplicating a common signal is different from adding independent variation. Matching is a necessary condition under the paper's definitions, not a sufficient recipe for control, and its statistical matching condition is not itself a causal model.

**Reconstructed question.** At which scale do Canadian and US duration, curve shape, liquidity, and flow require separate responses, and at which scale are they multiple measurements of one common movement?

**Right / wrong / missing.** Shared latent curves and economic-group distances are strong choices. It would be wrong to count 41 columns as 41 independent pieces of environmental variety or to call three independent horizon models a coherent multi-scale controller. Missing: sensitivity to the chosen economic grouping and to dependence changes that preserve individual feature marginals.

**No-data experiment.** Hold each channel's marginal process fixed while changing common-factor coupling and conditional dependence between groups. Add exact copies within a group, and then relabel redundant copies as spurious new groups. Compare the current group metric with a hierarchical factor/conditional-information representation. Separately compare independent horizon banks against one path process whose 60/120/240-minute distributions are its marginals. Score joint events, interval/MAE coverage, and decision regret. This can reveal whether apparent variety comes from independent evidence or a partitioning convention.

**Limit.** A stochastic forecaster need not satisfy the paper's exact deterministic matching condition. The transfer is a disciplined representation audit, not a demand that a trading model perfectly control the market.

## 4. Building the Observer into the System: Toward a Realistic Description of Human Interaction with the World

Chris Fields. Collected foundational paper, 42 pages. [Original text](coverage.md#c04).

**Passages.** Observer/black-box setup in §§2.2–2.5, approximately 244–529; Moore-style finite-observation argument and its consequences, approximately 530–930; §4 object identification and internal reference frames, especially 959–1120; cross-disciplinary discussion and conclusion, 1121–1280.

**Mechanism.** A finite input/output history generally does not uniquely identify the hidden machine that generated it. An observer brings an interface, reference criteria, and finite memory. Identifying which object is being measured is a different operation from measuring that object's changing state.

**Reconstructed question.** Which distinctions between continuation, absorption, common repricing, and local exhaustion are actually identifiable from our received quotes and tape, and which distinctions exist only in the simulator's private state?

**Right / wrong / missing.** Receiver-time observation, contract identity, hidden-truth separation, and the report's refusal to identify observed absorption with hidden absorption are unusually good matches. Treating five observed states as five physical mechanisms would be wrong; the implementation explicitly avoids it. Missing: an ambiguity experiment in which different mechanisms are observationally equivalent for an interval.

**No-data experiment.** Construct paired worlds with the exact same available observation prefix but different hidden decompositions, then distinct future distributions. Before a discriminating side channel arrives, the deployed predictor must produce identical forecasts in both worlds. Randomize that channel's delay and quality; compare to a privileged oracle only as an identifiability ceiling. Assess epistemic uncertainty and false causal certainty rather than blaming the model for failing to infer inaccessible state. Also vary reference identity or CTD information independently of quoted price.

**Limit.** Fields' broader no-boundary, quantum, and philosophical claims are the author's framework. The finite-observation and reference-identification insights can be used without treating all those claims as established market facts.

## 5. Philosophy-Guided Modelling and Implementation of Adaptation and Control in Complex Systems

State time and adaptation time are distinct. A target-directed training run that stops upon success differs from continuous homeostatic control in a changing milieu.

**Reconstructed question.** When the environment changes, which object changes quickly—the estimated state—and which object changes slowly—the rules by which we estimate or act—and what evidence authorizes each change?

Compare frozen parameters, continuous naive refitting, and fast state estimation plus slow rule adaptation using only matured labels. Keep each candidate's adaptation budget fixed. Measure overshoot, recovery delay, forgotten old-regime performance, and calibration/risk violations. This tests two time scales rather than merely declaring an architecture adaptive.

## 6. Philosophy-Guided Mathematical Formalism for Complex Systems Modelling

Patrik Christen and Olivier Del Fabbro. Collected mathematical/modelling paper, 8 pages, July 2022 version. [Original text](coverage.md#c06).

**Passages.** §III mathematical formalism, lines 216–413; §IV model creation, 414–605; §V conditional model equivalence, 606–677; conclusion, 678–779.

**Mechanism.** A common schema makes the state sets, neighborhood topology, update rules, adaptation rules, and goals explicit. Two models are conditionally equivalent when their relevant structures and operations match under the given conditions, not simply because both use the word “state.”

**Reconstructed question.** What exact mapping connects each mathematical object in the thesis to a CAD model component, and does that mapping preserve the operations that make the proposed mechanism work?

**Right / wrong / missing.** The present simulator has concrete, auditable mappings from shared curve coordinates to cash flows, futures, and observations. Score which change breaks equivalence and whether the predictor notices. This supplies a constructive test of representation-preserving transfer rather than a naming exercise.

**Limit.** The paper's conditional equivalence statements concern mathematical constructions. They do not establish that arbitrary cellular automata and neural networks share economic meaning or calibrated dynamics.

## 7. Reinforcement Learning in Categorical Cybernetics

Jules Hedges and Riu Rodríguez Sakamoto. Collected ACT/EPTCS paper, 17 pages. [Original text](coverage.md#c07).

**Passages.** §2 RL background, 81–226; §3 optics/parametrization, 227–372; §4 iteration, 373–524; §5 Bellman operators, 525–693; §6 model–agent–environment, 694–883; prediction and bandit special cases, 884–930; mathematical appendix read through line 1201.

**Mechanism.** The formalism separates an internal model, deployed policy, environment, and returned update information. Forward and backward interfaces compose without conflating belief changes with world dynamics. Prediction and bandits are special cases; general control lets actions change later states. Bellman properties still rely on their mathematical assumptions.

**Reconstructed question.** Where exactly does our prediction become an action, what state does that action change, and which subsequent observations should be credited to the action rather than treated as exogenous evidence?

**Right / wrong / missing.** Separate forecasting and touch-execution accounting are useful explicit interfaces. The current generator is unaffected by the demonstration strategy, so it is a passive prediction/decision experiment, not a test of an interacting market controller. This is a scope limit, not a reason to discard the baseline. Missing: action-conditioned dynamics and credit assignment when size, inventory, or impact matter.

**No-data experiment.** Add an action-feedback switch to an otherwise paired simulator. At zero impact, the same exogenous shocks must reproduce the passive baseline. At positive impact, orders alter temporary displacement, future quotes, and possibly observable flow; inventory constrains later actions. Compare a fixed forecaster with policies of several sizes, an impact-aware policy, and an oracle. Track forecast loss and execution utility separately. A strategy can degrade despite stable exogenous predictive skill as its own actions reshape the path.

## 8. The Agent Use of Agent Beings: Agent Cybernetics Is the Missing Science of Foundation Agents

Xinrun Wang, Chang Yang, He Zhao, Zhuoyi Lin, and Shuyue Hu. Collected position paper, 21 pages, May 2026 preprint. [Original text](coverage.md#c08).

**Passages.** Six laws around lines 80–164; architectural principles around 164–364; research agenda around 382–489; scientific-agent applications around 646–730; appendix FAQ at 984–1093.

**Mechanism.** Reliability over time requires environmental feedback, a controller representation of its own operation, retained memory, and a distinction between quick correction and slower structural change. Research feedback is useful when failures revise a hypothesis rather than merely trigger another attempt.

**Reconstructed question.** Can our research system retain why a mechanism failed and change the appropriate hypothesis while keeping its observation, chronology, and risk constraints stable?

**Right / wrong / missing.** Immutable forecasts, provenance, matured outcomes, and preserved stress results provide much of the necessary evidence infrastructure. **No-data experiment.** Give the controller a predeclared viability region over calibration, path-risk coverage, availability, and exposure. Run delayed-outcome worlds with temporary and permanent changes. Compare no adaptation, immediate-loss adaptation, and a controller with evidence accumulation, two time scales, and retained regime memory. Measure false changes, recovery time, and return-to-old-regime competence. Every outcome available for adaptation must carry its maturity timestamp.

## 9. Towards Quantum Cybernetics

Davide Girolami, Rebecca Schmidt, and Gerardo Adesso. Collected paper, 7 pages. [Original text](coverage.md#c09).

**Passages.** §II regulation and requisite variety, 145–280; §III quantum extensions, beginning 281; one-shot/non-iid and cost-function discussion around 342–398; applications/discussion around 399–546.

**Mechanism.** A regulator needs information correlated with disturbances and sufficient reachable responses. Merely having many possible internal states is not the same resource as knowing which disturbance occurred. Low outcome entropy does not establish that the outcome is desirable. Finite or nonergodic episodes may require a different evaluation from asymptotic iid entropy averages.

**Reconstructed question.** Which variables can our trading system actually keep within acceptable bounds, given its information delay and limited actions, even if the external price process remains uncertain?

**Right / wrong / missing.** Separate probability scores and price ledgers already recognize that a confident forecast and a good outcome differ. The model controls exposure and execution choices, not exogenous CGB prices. Missing: a stated controlled-variable/viability problem with limited actions, latency, and path-dependent penalties. Treating low predictive entropy as a control objective would be wrong.

**No-data experiment.** In a small discretized synthetic inventory/price model, enumerate the finite-horizon viable set under position caps, action limits, latency, and costs. Compare candidate policies against a dynamic-programming oracle with the same observation interface, plus a privileged-information upper bound. Include equally low-entropy but oppositely desirable outcomes. Test how survival probability changes with sensing quality and action capacity independently.

**Limit.** The quantum portion is a separate physical theory. The transferable information/control distinctions do not require asserting market quantum coherence or importing a quantum advantage.

## 11. Complexity Control

Korosh Mahmoodi, Scott E. Kerick, Piotr J. Franaszczuk, Paolo Grigolini, and Bruce J. West. Collected paper, 12 pages. [Original text](coverage.md#c11).

**Passages.** Temporal complexity discussion around 78–156; §2 basic concepts, 157–253, including crucial events at 182–207; coupled-map/learning construction around 254–365; results/discussion around 365–480.

**Mechanism.** The temporal organization of renewal events can matter independently of marginal fluctuation size. Coupling changes the driven system's event organization, and susceptibility depends on the system's current state. Heavy-tailed waiting times, time-varying complexity, and synchronization are distinct from ordinary contemporaneous correlation.

**Reconstructed question.** Does duration pressure end with a nearly constant hazard, or does its chance of ending depend on how long the episode has lasted and on where the coupled markets are in their response cycle?

**Right / wrong / missing.** Current latent pressures have a fixed AR persistence, absorption switches use constant probabilities conditional on switch state, and return innovations are Student-t. The observed model already has state age, which could help in a richer world. Fat return tails do not supply heavy-tailed event waiting times. Missing: a test of event-time/dwell structure and state-dependent transmission.

**No-data experiment.** Replace selected pressure/absorption episodes with semi-Markov renewal processes. Compare geometric, bounded heavy-tail, and age-dependent dwell laws while matching occupancy, mean dwell where finite, approximate one-step variance, and unconditional cross-market correlation. Use identical innovations where possible. Ablate the existing state-age feature and compare clock-time versus event-time predictors. Evaluate residual hazard calibration, continuation by episode age, and excursion coverage. Independently vary CAD–US coupling strength and susceptibility.

**Limit.** Do not infer a universal market power law from the paper's simulations. Its power-law/ergodicity arguments assume idealized distributions; finite truncation changes them. Some displayed map/clamping formulas are extraction-ambiguous, so this review transfers the mechanism, not an unverified literal implementation.

## 13. Computing with space: a tangle formalism for chora and difference

Marius Buliga. Collected mathematical paper, 56 pages, with quoted Bateson and Plato supplementary material. [Original text](coverage.md#c13).

**Passages.** Map/territory and front-end representation, lines 77–346; exploration and maps at different viewpoints, 347–670; simulation of spaces, 671–760; idempotent quasigroups and linearity, 902–1275; approximate difference/sum and limits, 1307–1534; difference gates/chora, 1535–1940; approximate Reidemeister III residual and uniform limit, approximately 1941–2138; Appendix I map accuracy/precision/resolution and scale/viewpoint stability, approximately 2139–2820; Appendix II idealizations/dilations, approximately 2821–3140; Bateson/Plato excerpts and references through line 3330.

**Mechanism.** An atlas is a set of local maps whose scale changes and changes of viewpoint must be compatible. Approximate differences compare representations; algebraic structure emerges under explicit contraction and uniform-limit assumptions. Some diagram rewrites are valid exactly, while another becomes valid only in a limiting linear structure, leaving a residual at finite scale. Appendix I separates accuracy, resolution, and precision and describes how errors cascade under magnification. Appendix II explicitly labels the additional idealizations needed for dilation structures.

**Reconstructed question.** If the same duration move is represented from another reference bond, another curve coordinate, another time scale, or another local operating point, does our model preserve the meaningful difference—or does the route through its maps change the answer?

**Right / wrong / missing.** Cash-flow repricing, explicit DV01 conventions, inverse YTM, and CTD minimization already instantiate meaningful maps and local sensitivities. The report acknowledges that cash/futures DV01 matching is only local, and that horizon banks are independent. Missing: quantitative compatibility tests between those maps. It would be wrong to assume that standardization creates full reference invariance, or that nonlinear valuation and time aggregation can always be reordered without a residual.

**No-data experiment.** First test exact coordinate changes: convert units or apply a bijective representation, transform forecast distributions back to the same price/P&L target, and require consistent results within declared numerical tolerance. Then study deliberately approximate transformations: linear DV01 versus full cash-flow repricing; reference change before versus after local residualization; aggregation before versus after nonlinear valuation; and short-horizon marginals versus a full-horizon path law. Sweep perturbation size and distance to CTD switch boundaries. Report the noncommutation residual and whether it shrinks in a smooth local regime; do not require smooth convergence at a genuine switch. Finally increase quote rounding and observation noise to separate resolution error from forecast uncertainty.

**Limit.** The experiment is a proposed structural translation, not a claim that the existing feature space satisfies Buliga's dilation axioms. Tangle diagrams were flattened in extraction and several equations have apparent typographical or extraction ambiguities. The full available text, including the substantial appendices and philosophical excerpts, was read; no diagrammatic proof certification is claimed.

## Minimal discriminating program for the next study

This is a design recommendation, not an executed experiment or a request to alter the saved study.

| Priority | Predeclared intervention | What would count as a discriminating result |
|---|---|---|
| 1 | Endpoint-only classifier versus current mixture, plus state/flow/history ablations on paired worlds | Separate directional gain from magnitude/MAE gain; show whether a state mechanism contributes when endpoint class information is held fixed |
| 2 | Matched-marginal temporal-memory and semi-Markov dwell worlds | History/age helps only in worlds where it contains additional predictive information; test both short-lived and persistent disturbances |
| 3 | One coherent full-path distribution versus independent horizon banks | Improve joint-horizon consistency and proper path scores without merely widening every bound; retain endpoint scores as separate evidence |
| 4 | Exact and approximate representation changes | Exact changes preserve the target law; approximation residuals vary predictably with scale, noise, and CTD boundaries |
| 5 | Observationally equivalent hidden worlds with delayed distinguishing channels | No impossible hidden-state discrimination before information arrives; useful uncertainty or robust decisions under unresolved ambiguity |
| 6 | Frozen versus two-timescale adaptation, then optional own-action feedback | Adapt only on mature evidence; distinguish recovery from noise-chasing and distinguish passive skill from action-conditioned profitability |

For every new family, publish the generator assumptions, observation operator, forecaster, policy, objective, and admissible interventions separately. Reuse random streams for paired comparisons where possible; keep new development and untouched evaluation seeds distinct; evaluate sessions or episodes rather than treating overlapping paths as independent samples. These are executable formal tests available before any real-data calibration. Their role is to reject weak mechanisms and clarify which claims deserve eventual market testing.
